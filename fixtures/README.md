# Demo workspace fixtures

Committed artifacts for the **DEMO-QA** manual demo (canonical source of truth).

| File | Purpose |
|------|---------|
| `demo-workspace.sqlite` | Living demo DB — default `DB_PATH` for `npm run dev` |
| `demo-qa-seed-data.json` | Replay manifest — regenerated by `npm run demo:sync-seed` |

## Workflow

1. Run `npm run dev` — API uses `fixtures/demo-workspace.sqlite` by default.
2. Edit DEMO-QA in the UI (requirements, tests, runs, etc.).
3. Checkpoint and sync seed artifacts:

```bash
npm run demo:checkpoint -- --sync
```

4. Commit `demo-workspace.sqlite`, `demo-qa-seed-data.json`, and `src/seed/demo-qa-constants.ts`.

E2E copies `demo-workspace.sqlite` and adds `DEMO-QA-EMPTY` at reset time (`npm run e2e:reset-db`).

Personal scratch databases: set `DB_PATH=./data/my.sqlite` (gitignored).
